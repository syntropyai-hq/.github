## Projects

| Project | What it does | Status |
|---|---|---|
| **[Syntropy](https://github.com/syntropyai-hq/syntropy)** | Runs one large model across every GPU, memory tier and machine you own. Placement is decided by measuring your hardware, and output matches the reference by default. Rust, with native kernels for CUDA, HIP, Metal, Vulkan and the CPU. | Pre-alpha: milestone M0a in progress |

## How we work

- **Measured, not assumed.** A target says it is one, an estimate shows its derivation, and a measurement names the commit, the hardware and how it was taken.
- **One change, one pull request.** Every change is squash-merged from a pull request with a conventional-commit title, `type(scope): subject`, and passes the same checks whoever wrote it.
- **Signed off.** Every commit carries a Developer Certificate of Origin sign-off. There is no CLA.
- **Licensed MIT OR Apache-2.0**, at your option. Contributions come in under the same terms.

Found a vulnerability? Report it privately through the affected repository's **Security** tab, not in a public issue.
